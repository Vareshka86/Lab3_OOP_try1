## Условие задания

Разработать программу согласно номеру варианта, которая содержит класс со следующими условиями:

1. Конструкторы — 3 шт.
2. Перегрузка унарных операций, 4 варианта: постфиксный и префиксный инкремент и декремент.
3. Перегрузка арифметического присваивания: `+=`, `-=`, `*=`, `/=`.
4. Перегрузка бинарных операций: `+`, `-`, `*`, `/`, `<`, `>`, `<=`, `>=`, `==`, `!=`.

В программе также должно быть одно статическое поле и деструктор, отличный от деструктора по
умолчанию. Основной функционал программы должен использовать все перегрузки и конструкторы из
пунктов 1–4. В реализации бинарных операций `+`, `-`, `*`, `/` использовать перегрузки `+=`, `-=`,
`*=`, `/=`.

**Вариант 5.** Калькулятор многочленов 2-й степени: программа работает с многочленом вида
ax² + bx + c, класс Polynomial. Примеры перегрузок: унарные — увеличение и уменьшение
коэффициентов; арифметические — сложение многочленов, умножение на число; сравнение — значений
при определённом x. В программе должна быть возможность найти корни и узнать, сколько раз с
последнего запуска программы использовалась функция поиска корней.

## Как решено (v0.1)

Диаграмма классов текущей версии — на странице @ref part3.

| Элемент | Что делает |
|---------|------------|
| `Polynomial()` | конструктор по умолчанию — нулевой многочлен 0 |
| `Polynomial(a, b, c)` | параметризованный конструктор — многочлен ax² + bx + c; бесконечность и «не число» отклоняет исключением |
| `Polynomial(const Polynomial&)` | конструктор копирования — та же тройка коэффициентов |
| `~Polynomial()` | деструктор — уменьшает счётчик существующих многочленов |
| `getA()`, `getB()`, `getC()` | коэффициенты |
| `valueAt(x)` | значение в точке по схеме Горнера: (a·x + b)·x + c |
| `findRoots(x1, x2)` | действительные корни; увеличивает статический счётчик поисков |
| `toString()`, `operator<<` | запись многочлена в привычном виде: «x² - 3x + 2», «-x² + 4», «0» |
| `getRootSearchCount()`, `getExistingCount()` | статические методы: значения счётчиков |

Код: Polynomial.h (объявление и документация), Polynomial.cpp (реализация), main.cpp (меню).
Модуль ввода дополнен функцией readDouble(): коэффициенты бывают дробными, и разделителем можно
ставить как точку, так и запятую.

## Статические поля

```cpp
static int rootSearchCount_;   // сколько раз искали корни (требование варианта 5)
static int existingCount_;     // сколько многочленов существует сейчас
```

Статическое поле одно на весь класс, а не своё у каждого объекта. Поэтому в `rootSearchCount_`
накапливаются вызовы `findRoots()` для **всех** многочленов. Метод `findRoots()` объявлен `const` —
он не меняет коэффициенты, — но увеличивает счётчик: статическое поле не входит в объект, и
константность метода на него не распространяется.

## Деструктор и счётчик существующих многочленов

Задание требует деструктор, отличный от деструктора по умолчанию. Деструктор уменьшает
`existingCount_`, а все три конструктора его увеличивают (параметризованный — после проверки
коэффициентов). Так счётчик показывает, сколько многочленов существует прямо сейчас, — в меню это
строка «Многочленов в памяти». Во время вычислений создаются и временные объекты (например,
`P = Polynomial(a, b, c)` создаёт временный многочлен и присваивает его P); деструктор уничтожает
их, и счётчик остаётся верным. Сообщений деструктор не печатает: в калькуляторе временных объектов
много, и сообщения засорили бы вывод.

## Поиск корней

| Случай | Результат |
|--------|-----------|
| a ≠ 0, D = b² − 4ac > 0 | два корня (−b ± √D) / 2a, по возрастанию |
| a ≠ 0, D = 0 | один корень −b / 2a |
| a ≠ 0, D < 0 | действительных корней нет |
| a = 0, b ≠ 0 | линейное уравнение: один корень −c / b |
| a = 0, b = 0, c ≠ 0 | корней нет |
| a = b = c = 0 | корень — любое число (`INFINITE_ROOTS`) |

Дробные вычисления дают погрешность: для 0,1x² − 0,2x + 0,1 дискриминант получается не ровно 0, а
очень маленьким числом. Поэтому числа меньше 10⁻¹² по модулю считаются нулём.

## Защита от ошибок

- **Ввод** — коэффициенты и x читает readDouble(): «abc», «1.2.3», «1e999» отклоняются, «2,5» читается как 2.5.
- **Коэффициенты** — параметризованный конструктор не создаёт многочлен с бесконечным или
  неопределённым коэффициентом (исключение `std::invalid_argument`).
- **«Минус ноль»** — вместо «-0» выводится «0».
- **Проверка.** Отдельная тестовая программа — 31 проверка из 31: счётчик при каждом
  конструкторе, присваивании и уничтожении временных объектов; отказ конструктора; запись
  многочлена в 7 вариантах; значение в точке; поиск корней во всех случаях таблицы, включая
  a < 0 (порядок корней) и погрешность дискриминанта; счётчик поисков.
