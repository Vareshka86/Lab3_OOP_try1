Версия v0.2. Класс Polynomial получил перегрузку пунктов 2–4 задания, кроме сравнений:
инкремент и декремент в двух формах, арифметическое присваивание и бинарные `+`, `-`, `*`, `/`.
Сравнения — в части 3.

## Что требуется

- Перегрузка унарных операций, 4 варианта: постфиксный и префиксный инкремент и декремент.
- Перегрузка арифметического присваивания: `+=`, `-=`, `*=`, `/=`.
- Перегрузка бинарных операций `+`, `-`, `*`, `/` — **с использованием** `+=`, `-=`, `*=`, `/=`.
- Вариант 5: унарные — увеличение и уменьшение коэффициентов; арифметические — сложение
  многочленов, умножение на число.

## Как решено

![Диаграмма классов Polynomial, версия v0.2](uml/Polynomial.png)

| Операция | Что делает | Возвращает |
|----------|------------|------------|
| `++p`, `--p` | все три коэффициента ±1 | ссылку на сам объект (уже изменённый) |
| `p++`, `p--` | все три коэффициента ±1 | копию **прежнего** значения |
| `p += q`, `p -= q` | складывает и вычитает коэффициенты двух многочленов | ссылку на `p` |
| `p *= k`, `p /= k` | умножает и делит каждый коэффициент на число k | ссылку на `p` |
| `p + q`, `p - q` | новый многочлен — сумма и разность (через `+=`, `-=`) | новый объект |
| `p * k`, `k * p`, `p / k` | новый многочлен, умноженный или делённый на число (через `*=`, `/=`) | новый объект |

Многочлены умножаются и делятся только на число: произведение двух многочленов второй степени
имеет четвёртую степень и в класс ax² + bx + c не помещается. Так и сформулирован вариант 5:
«сложение полиномов, умножение на число».

## Префиксная и постфиксная форма

```cpp
Polynomial& operator++();      // ++p: префиксная
Polynomial  operator++(int);   // p++: постфиксная (int - только метка)

Polynomial Polynomial::operator++(int)
{
    Polynomial old(*this);     // копия прежнего значения
    ++(*this);                 // меняем объект через префиксную форму
    return old;                // возвращаем прежнее значение
}
```

Префиксная форма сначала меняет объект и возвращает **ссылку** на него — поэтому `++p` уже новое
значение. Постфиксная форма возвращает **копию** прежнего значения, поэтому её тип — `Polynomial`,
а не ссылка: вернуть ссылку на локальную переменную `old` нельзя, она исчезнет после выхода из
функции. Параметр `int` в постфиксной форме не используется — по нему компилятор отличает `p++` от
`++p`. В меню пункт 15 показывает разницу: «P++ вернул прежнее значение», «++P вернул новое».

## Бинарные операции через составное присваивание

```cpp
Polynomial operator+(Polynomial lhs, const Polynomial& rhs)
{
    lhs += rhs;      // используем существующую логику
    return lhs;
}
```

Левый операнд передан **по значению**: функция получает копию, увеличивает её через `+=` и
возвращает. Сами `p` и `q` не меняются. Логика сложения записана в одном месте — в `+=`; если её
исправить, исправится и `+`. Так требует задание, и так сделан пример на сайте курса. Функции
объявлены дружественными (`friend`) внутри класса, как в этом примере.

Для `2 * p` нужен отдельный оператор `operator*(double, Polynomial)`: слева стоит число, и метод
класса тут не подходит.

## Ошибки операций

Все операции, меняющие многочлен, записывают новые коэффициенты через закрытый метод
`setCoefficients()`: он сначала проверяет, что все три значения конечные, и только потом меняет
поля. Поэтому при ошибке многочлен остаётся прежним.

| Ошибка | Исключение |
|--------|------------|
| `p /= 0`, `p / 0` — деление на ноль | `std::invalid_argument` |
| множитель или делитель — бесконечность | `std::invalid_argument` |
| результат перестал быть конечным (например, 10³⁰⁸ · 10) | `std::overflow_error` |

Меню перехватывает эти исключения у каждого пункта: выводит «Ошибка: деление на ноль.
Многочлены не изменились.» и продолжает работу.

**Проверка.** Тестовая программа части 2 — 29 проверок из 29: четыре формы `++`/`--` и их
возвращаемые значения, цепочки `++++t` и `(p += q) += q`, все составные и бинарные операции,
`2 * p == p * 2`, неизменность операндов бинарных операций, деление на ноль, бесконечный
множитель, переполнение в `*=`, `+=`, `/=` (многочлен не меняется), уничтожение временных
объектов. Проверки части 1 — 31 из 31.

  1 - ++P   (префиксный инкремент)
