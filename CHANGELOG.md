# История версий

Здесь записано, что было сделано в каждой версии лабораторной работы.
Каждой версии в git соответствует метка (тег) с тем же именем.
Новые версии добавляются сверху.

## v0.2 — 2026-10-03

Выполнена часть 2 из 3: перегрузка унарных операций, арифметического присваивания и бинарной
арифметики.

### Сделано

- `++` и `--` в префиксной и постфиксной форме: все коэффициенты ±1; префиксные возвращают ссылку
  на изменённый объект, постфиксные — копию прежнего значения.
- `+=`, `-=` с многочленом, `*=`, `/=` с числом. Деление на ноль и бесконечный множитель —
  `std::invalid_argument`, переполнение — `std::overflow_error`; многочлен при ошибке не меняется
  (общая проверка в закрытом методе `setCoefficients`).
- Бинарные `+`, `-`, `*`, `/` — дружественные функции, реализованные через `+=`, `-=`, `*=`, `/=`;
  добавлено `k * p`.
- Меню: пункты 9–15 — сумма и разность, умножение и деление на число, составное присваивание,
  четыре формы инкремента и декремента с показом возвращаемого значения; ошибки операций
  выводятся, программа продолжает работу.
- Диаграмма классов обновлена, страница документации `pages/part2.md`, README.

### Проверено

- Сборка `g++ -std=c++14 -Wall -Wextra -pedantic -static` (g++ 16.2.0) — без ошибок и предупреждений.
- Тестовая программа части 2 — 29 проверок из 29: возвращаемые значения `++`/`--`, цепочки, все
  операции, неизменность операндов бинарных операций, деление на ноль, переполнение, уничтожение
  временных объектов. Проверки части 1 — 31 из 31.
- Меню: все новые пункты, деление на ноль в `/=` и `/`.
- Doxygen 1.18.0 собирает документацию без предупреждений.

### Следующая версия (v1.0)

- Перегрузка сравнений `<`, `>`, `<=`, `>=`, `==`, `!=` значений многочленов в заданной точке x;
  пункт меню, показывающий все операции.

## v0.1 — 2026-10-03

Выполнена часть 1 из 3: класс Polynomial (вариант 5 — калькулятор многочленов 2-й степени) без
перегрузки операций.

### Сделано

- Класс `Polynomial` (`Polynomial.h` / `Polynomial.cpp`): коэффициенты a, b, c; три конструктора —
  по умолчанию, с параметрами (бесконечность и «не число» отклоняются исключением
  `std::invalid_argument`), копирования; деструктор, уменьшающий счётчик существующих многочленов;
  оператор присваивания `= default`.
- Статические поля: `rootSearchCount_` — число вызовов поиска корней с запуска программы
  (требование варианта 5), `existingCount_` — число существующих многочленов.
- `valueAt(x)` — значение в точке по схеме Горнера; `findRoots(x1, x2)` — действительные корни во
  всех случаях (два, один, нет, линейное уравнение, любое число); `toString()` и `operator<<` — запись
  «x² - 3x + 2».
- Модуль ввода: функция `readDouble` — дробные числа с точкой или запятой.
- Меню калькулятора: многочлены P и Q, ввод, обнуление, копирование, значения в точке, корни,
  счётчик поисков.
- Диаграмма классов `uml/Polynomial.puml` (картинка `uml/Polynomial.png`), страница документации
  `pages/part1.md`, README.

### Проверено

- Сборка `g++ -std=c++14 -Wall -Wextra -pedantic -static` (g++ 16.2.0) — без ошибок и предупреждений.
- Тестовая программа — 31 проверка из 31: счётчики при конструкторах, присваивании и уничтожении
  временных объектов, отказ конструктора, запись многочлена, значение в точке, все случаи поиска
  корней (в том числе a < 0 и погрешность дискриминанта), счётчик поисков.
- Меню: все пункты; неверный ввод («abc», «1.2.3», «1e999»), дробная часть через запятую.
- Doxygen 1.18.0 собирает документацию без предупреждений; диаграмма — PlantUML 1.2026.8.

### Следующая версия (v0.2)

- Перегрузка `++`/`--` (префиксные и постфиксные), `+=`, `-=`, `*=`, `/=` и бинарных `+`, `-`, `*`,
  `/`, реализованных через составное присваивание.
